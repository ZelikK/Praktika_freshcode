# Zenith ToDo - Сучасний веб-додаток "ToDo List"
<img width="1918" height="912" alt="image" src="https://github.com/user-attachments/assets/8e40d492-bac9-4115-bbfe-a30b8d7a44e0" />

> **Zenith ToDo** — це повнофункціональний, естетичний веб-додаток для керування завданнями, натхненний найкращими рішеннями **Todoist** та **Microsoft To Do**. Додаток поєднує швидкість локального сховища браузера (`localStorage`) та надійність серверної бази даних (`SQLite`) із резервним збереженням у файлову систему (`JSON`).

---

## ✨ Реалізований функціонал за вимогами

### 1. Базові операції із завданнями
- **Додавання завдань**:
  - Швидке додавання через верхній рядок з підтримкою клавіші `Enter`.
  - Встановлення пріоритету за шкалою Todoist: **P1 (Високий)**, **P2 (Середній)**, **P3 (Низький)**, **P4 (Звичайний)**.
  - Вибір дедлайну (календар дат) та призначення списку/проекту.
  - Підтримка швидкої клавіші `Q` для миттєвого фокусу на полі додавання.
- **Відмітка завдань як виконані**:
  - Круглий інтерактивний чекбокс з кольоровим контуром відповідно до пріоритету.
  - Плавна анімація галочки та закреслення тексту.
  - Мелодійний звуковий ефект успіху при виконанні завдання (через чистий Web Audio API, можна вимкнути або увімкнути).
  - Підтримка багаторівневих підзавдань (Checklist / Subtasks) у кожному завданні з індикатором прогресу (напр. `3/4`).
- **Видалення завдань**:
  - Швидке видалення в 1 клік зі списку завдань (іконка кошика при наведенні).
  - Видалення всередині детальної бічної панелі з підтвердженням.

### 2. Подвійне збереження та синхронізація (Dual Persistence & Offline)
- **Браузер (`localStorage`)**:
  - Всі завдання та категорії миттєво зберігаються у локальному сховищі браузера (Optimistic UI).
  - Додаток відкривається за 0 мс та повноцінно працює навіть без інтернет-з'єднання чи при вимкненому сервері.
- **Серверна база даних (`SQLite`)**:
  - Всі операції синхронізуються із базою даних `data/todos.db` через Flask REST API.
  - Повноцінна схема таблиць `tasks` та `categories`.
- **Файлова система сервера (`JSON backup`)**:
  - При кожній зміні автоматично оновлюється файл `data/todos_backup.json`, забезпечуючи експорт та надійне збереження у файловій системі сервера.
- **Менеджер синхронізації (`SyncManager`)**:
  - Автоматичне оновлення стану мережі (`online` / `offline`).
  - Вирішення можливих конфліктів за часовою міткою `updated_at`.
  - Індикатор статусу синхронізації у лівому нижньому кутку та кнопка ручної синхронізації.

### 3. Найкращі функції з Todoist та Microsoft To Do

| Функція | Джерело натхнення | Опис |
|---|---|---|
| **"Мій день" (My Day)** | Microsoft To Do | Смарт-список завдань на сьогодні з поточною датою українською мовою. |
| **"Важливі" (Starred)** | Microsoft To Do | Швидке закріплення найважливіших завдань за допомогою зірочки в один клік. |
| **"Заплановані" (Upcoming)** | Todoist & MS To Do | Перегляд усіх завдань, що мають встановлений термін виконання, з підсвічуванням прострочених. |
| **Кольорові пріоритети (P1-P4)** | Todoist | Червоний (P1), помаранчевий (P2), синій (P3), нейтральний (P4) з кольоровими рамками. |
| **Бічна панель деталей (Drawer)** | Microsoft To Do | Права висувна панель для детального редагування: назва, замітки/опис, підзавдання (кроки), дедлайн. |
| **Списки та проекти** | Todoist | Вхідні, Робота, Особисте, Навчання, Покупки + створення власних списків з вибором кольорового маркера. |
| **Темна та світла теми** | Сучасний UI | Перемикач Dark / Light mode із збереженням обраної теми в пам'яті. |
| **Пошук та сортування** | Todoist | Миттєва фільтрація (гаряча клавіша `/`) та сортування за датою, пріоритетом або алфавітом. |

## 🚀 Як запустити проект

### Варіант 1. Запуск у 1 клік (Windows)
Просто двічі клікніть на файл:
```cmd
start.bat
```
Скрипт автоматично:
1. Знайде Python у системі.
2. Встановить залежності (`flask`, `flask-cors`), якщо вони ще не встановлені.
3. Автоматично відкриє браузер за адресою [http://127.0.0.1:5000](http://127.0.0.1:5000).
4. Запустить backend сервер.

---

### Варіант 2. Запуск через командний рядок

1. Встановіть необхідні бібліотеки:
```bash
pip install -r requirements.txt
```

2. Запустіть сервер:
```bash
python app.py
```

3. Відкрийте веб-браузер:
[http://127.0.0.1:5000](http://127.0.0.1:5000)

## 📡 REST API Ендпоінти

| Метод | URL | Опис |
|---|---|---|
| `GET` | `/api/todos` | Отримати всі завдання (підтримує фільтри `?filter=today/starred/completed` та `?category=...`) |
| `POST` | `/api/todos` | Створити нове завдання |
| `GET` | `/api/todos/<id>` | Отримати детальну інформацію про завдання |
| `PUT` | `/api/todos/<id>` | Оновити завдання (назва, опис, пріоритет, дедлайн, підзавдання) |
| `PATCH` | `/api/todos/<id>/toggle` | Змінити статус виконання (виконано / активне) |
| `PATCH` | `/api/todos/<id>/star` | Закріпити / прибрати позначку важливого (зірочка) |
| `DELETE` | `/api/todos/<id>` | Видалити завдання |
| `POST` | `/api/todos/sync` | Повна двостороння синхронізація між клієнтом (localStorage) та сервером (SQLite) |
| `GET` | `/api/categories` | Отримати список категорій/проектів |
| `POST` | `/api/categories` | Створити нову категорію |
| `GET` | `/api/stats` | Статистика завдань (всього, виконано, активні, важливі, на сьогодні) |
| `GET` | `/api/health` | Перевірка стану сервера та сховищ |

## ⌨️ Гарячі клавіші (Keyboard Shortcuts)
- **`Q`** або **`Й`** — Швидкий перехід до рядка додавання завдання.
- **`Enter`** — Зберегти нове завдання або додати підзавдання.
- **`/`** — Миттєвий перехід до пошуку завдань.
- **`Esc`** — Закрити бічну панель редагування чи модальне вікно.
